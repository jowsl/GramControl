# GramControl

O GramControl é um ecossistema de software desenvolvido para automatizar e otimizar a gestão comercial, logística e financeira de empresas fornecedoras de gramados esportivos, com foco inicial em campos de futebol.\
\
O objetivo principal do sistema é eliminar processos manuais em campo, reduzir o tempo de fechamento de orçamentos e centralizar a comunicação entre vendedores, administradores, clientes e prestadores de serviços (instaladores).
