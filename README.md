# GramControl

O GramCoure/cadastrar-cliente-campontrol é um ecossistema de software desenvolvido para automatizar e otimizar a gestão comercial, logística e financeira de empresas fornecedoras de gramados esportivos, com foco inicial em campos de futebol.

O objetivo principal do sistema é eliminar processos manuais em campo, reduzir o tempo de fechamento de orçamentos e centralizar a comunicação entre vendedores, administradores, clientes e prestadores de serviços (instaladores).

## Compilação

Para compilar o projeto, execute os seguintes comandos no terminal:

```bash
make app
```
```bash
make test
```
## Execução
```bash
rm -f gramcontrol.db
./bin/gramcontrol
```

Isso irá gerar os arquivos executáveis na pasta `bin/`.
